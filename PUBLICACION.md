# PUBLICACIÓN RÁPIDA

## Opción recomendada de trabajo
1. Crea un repositorio en el GitHub de Miguel Segura llamado, por ejemplo:
   `simulador-costos-emprendimientos`
2. Sube todo el contenido de esta carpeta.
3. Conserva `index.html` en la raíz del repositorio.
4. Conecta el repositorio al servicio de hosting que elijas.
5. Cada actualización futura debe hacerse mediante una nueva versión/commit.

## Regla de producto
Los alumnos reciben el enlace publicado, no el archivo fuente.
El repositorio queda bajo control de Miguel Segura. 1122Lab corresponde al proyecto en el que se utiliza este simulador.
