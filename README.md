# 1122Lab — Simulador de Costos para Ideas de Negocio

**Versión oficial:** 1.0  
**Autor:** Miguel Segura Verano  
**Uso:** 1122Lab

## Qué contiene esta versión
Aplicación web educativa para trabajar:
- costos variables y costos fijos;
- inversión inicial;
- precio, margen y punto de equilibrio;
- proyección de 12 meses;
- escenarios Base, Optimista, Pesimista y Tu reto;
- tablero e interpretación pedagógica;
- reporte final imprimible / guardable como PDF.

El escenario **Base** toma automáticamente el precio, las unidades del mes 1 y el crecimiento ingresados en la pestaña **Ventas**.

## Cómo probarla en una PC
1. Abre `index.html` con Chrome, Edge o Firefox.
2. No requiere instalar Excel ni software adicional.
3. Los cálculos se ejecutan en el navegador.

## Cómo publicarla
La carpeta está preparada para un hosting estático. Puedes subirla a GitHub y desplegarla con GitHub Pages, Cloudflare Pages, Netlify u otro servicio compatible.
